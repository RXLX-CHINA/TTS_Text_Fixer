# TTS文案多音字替换助手

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)

一个面向 TTS（文本转语音）场景的多音字智能替换工具，提供 **GUI 图形界面** 和 **CLI 命令行** 两种交互方式，帮助您将文本中的多音字替换为同音字或拼音，避免 TTS 引擎读错。

---

## 📌 项目简介

在中文 TTS 中，多音字误读是常见痛点。本工具通过：
- **内置 1300+ 带调音节替换字典**（`replace_dict.py`）
- **可自定义的多音字词汇表**（`word_readings.json`）
- **pypinyin 上下文消歧 + 词汇优先匹配** 的智能策略
- **直观的交互界面**（点击跳转、着色反馈、批量操作）

帮助您快速、准确地预处理文本，极大提升 TTS 的发音准确率。

## ✨ 功能特性

- **🔍 智能识别多音字**：基于 pypinyin 获取所有读音，并利用上下文推荐最合适读音。
- **🧠 词汇优先匹配**：内置可扩展的 `word_readings.json`，支持“中弹”→“zhong4”等特定词汇读音。
- **🔀 变体匹配**：自动识别“中了弹”、“中过弹”等插入助词的变体。
- **🎯 四色状态体系**：
  - 智能保留（白底红字）
  - 智能忽略（亮灰）
  - 智能替换（绿底）
  - 手动修改（浅蓝）
- **🖱️ 交互丰富**：
  - 点击原文多音字跳转表格
  - 表格右键菜单（多选批量操作）
  - 悬停提示替换结果
  - 一键替换 / 批量忽略 / 批量替换 / 一键忽略轻声
- **📁 可编辑词汇表**：支持在工具内直接编辑 `word_readings.json`，实时重新加载。
- **🔄 替换为拼音**：当某读音无可用替换字时，可选择替换为拼音（如 `zhong4`），适合支持拼音输入的 TTS。
- **🎨 GUI + CLI 双版本**：满足不同使用场景。

## 🛠️ 技术细节

### 架构概览

```markdown
├── GUI.py # 图形界面（Tkinter）  
├── CLI.py # 命令行界面  
├── replace_dict.py # 核心替换字典（1300+ 带调音节→替换字）  
├── word_readings.json # 多音字词汇表（可自定义）  
└── requirements.txt # 依赖  
```

### 核心依赖
- **Python 3.8+**
- **pypinyin** (>=0.49.0) – 汉字转拼音及上下文消歧
- **rich** (可选, CLI 美化) – 终端表格展示
- **tkinter** (内置) – GUI

### 关键算法

#### 1. 多音字检测与推荐
- 使用 `pypinyin.pinyin(chars, heteronym=True)` 获取每个字的所有读音。
- 使用 `pypinyin.pinyin(text, heteronym=False)` 获取基于上下文的推荐读音（传入原始字符串，而非字符列表）。
- 若上下文消歧结果长度不一致（含特殊字符时），自动回退到逐字符默认读音，确保索引对齐。

#### 2. 词汇优先匹配
- 遍历 `word_readings.json` 中的词汇，检查当前多音字是否属于某个词汇（通过 `_is_word_at_position`）。
- 支持助词变体（“了”、“着”、“过”插入），如“中了弹”匹配“中弹”。
- 若匹配到词汇，直接应用其指定的读音，优先级高于上下文推荐。

#### 3. 智能策略（`apply_smart_policy`）
按顺序执行：
1. 词汇匹配 → 若匹配且读音有替换字，设为“智能替换”；若匹配但无替换字且 `fallback_to_pinyin` 开启，则替换为拼音。
2. 特殊规则：
   - `的` → 智能保留（不替换）
   - `地` / `得` → 若推荐为 `dei3` 且无替换字，按拼音或保留；否则默认替换为“的”（确保轻声）。
   - `一`、`不` → 智能忽略（信任 TTS 变调）
   - 推荐读音以 `5` 结尾（轻声）→ 智能忽略
3. 其余多音字 → 智能保留（预判无需修改）

#### 4. 替换生成
- 按字符索引顺序拼接，支持替换为多字（拼音）或单字，长度变化不影响后续索引。
- 最终输出保留所有非多音字内容。

## 📦 安装与使用

### 安装
```bash
# 克隆仓库
git clone https://github.com/yourusername/pinyin-replacer.git
cd pinyin-replacer

# 安装依赖
pip install -r requirements.txt

# （可选）安装 nuitka 用于打包 exe
pip install nuitka
```

  
### GUI版本（推荐）
直接运行：
```bash
python GUI.py
```

#### 界面操作流程
1.**输入文本**：粘贴或通过“打开文件”载入。

2.**分析多音字**：点击按钮，系统自动识别并着色。

3.**查看与修改**：

  - 表格中双击行可修改读音或自定义替换。

  - 右键多选行进行批量操作。

  - 点击原文中的多音字可跳转至表格。

4.**生成结果**：点击“生成结果”预览，可导出到文件。

  
### CLI版本
#### 交互模式（默认）
```bash
python CLI.py "你的文本"
python CLI.py -f input.txt
```
进入交互菜单后，可按数字键执行替换、忽略、预览等操作。

#### 非交互模式（直接替换）
```bash
python CLI.py -f input.txt --no-interactive -o output.txt
```

#### 启用拼音后备
```bash
python CLI.py "目的" --fallback-pinyin
```

## 📝 自定义扩展指南
### 1.扩展替换字典（`replace_dict.py`）
此文件定义了每个带调音节对应的“最佳替换字”。格式：
```python
replace_dict = {
    "zhong1": "钟",
    "zhong4": "众",
    # ...
}
```
 - **键**：拼音 + 声调数字（如 `zhong4`），轻声用 `5`（如 `de5`）。

 - **值**：该读音对应的一个 **非多音字**（或您认为 TTS 能正确读出的字）。

如果某音节没有合适的替换字，请设为 `None`。

**扩展建议**：您可以根据自己的 TTS 引擎特点，替换为更合适的字，或添加生僻字的读音条目。

### 2.扩展词汇表（`word_readings.json`）
此文件用于指定特定词汇中多音字的读音，优先级高于上下文消歧。格式：
```json
{
  "中弹": {"中": "zhong4"},
  "目的": {"的": "di4"},
  "弹射": {"弹": "tan2"},
  "重庆": {"重": "chong2"}
}
```
 - **键**：词汇（字符串）

 - **值**：`{"多音字": "读音"}`，可同时指定多个字。

 - **添加新词**：直接按格式追加即可，工具可实时重载。

 - **支持变体**：如“中了弹”、“中过弹”会自动匹配“中弹”。

>[!NOTE]
>**注意**：若词汇表中某字读音无替换字（replace_dict 中为 None），则工具会根据全局“替换为拼音”设置决定是否替换为拼音。

### 3.扩展智能规则
您可以在 `GUI.py` / `CLI.py` 的 `apply_smart_policy` 方法中添加自己的规则，例如：

 - 对特定字强制忽略
 - 对特定上下文应用自定义替换
